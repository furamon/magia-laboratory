# Quickstart: 個人創作サイト（Astro + Svelte）

**Date**: 2026-08-24
**Branch**: `main`（仕様上の想定ブランチ: `001-personal-creative-site`）

本ガイドは、実装完了後の機能検証手順を定義する。詳細なデータ定義は [data-model.md](./data-model.md)、ルート・コンポーネント契約は [contracts/](./contracts/) を参照すること。

## 前提条件

- Node.js >= 22.12.0 / bun がインストール済み
- 依存関係がインストール済み（`bun install`）

## セットアップ

```bash
# 依存関係のインストール
bun install

# 開発サーバーの起動（バックグラウンド）
astro dev --background
```

## 検証シナリオ

### シナリオ 1: トップページのレイアウト（User Story 1・FR-001/FR-002/FR-003）

**手順**:

1. ブラウザで `http://localhost:4321/` を開く
2. ページ上部に固定ヘッダー（サイトタイトル「Magia Laboratory」・ナビゲーション「Game / Lily / Creation / Diary / RSS」・検索ボタン）が表示されることを確認
3. 中央にタイトル「Magia Laboratory」・説明文「ゲーム攻略、百合作品などのサイト。」・カテゴリボタン群（Game / Creation / Lily / etc. / Some Links）が表示されることを確認
4. 下部にフッター（コピーライト・Privacy Policy リンク・テーマ切替ボタン・トップへ戻るボタン）が表示されることを確認
5. ページをスクロールし、ヘッダーが画面上部に固定されたままであることを確認

**期待結果**: 旧サイトと同等の配置で 3 領域（ヘッダー・メイン・フッター）が表示される。

### シナリオ 2: ナビゲーションとカテゴリリンク（User Story 2）

**手順**:

1. ヘッダーの「Game」リンクをクリック → `/game` ページへ遷移することを確認
2. トップページに戻り、「Game」カテゴリの「PlayGuide」ボタンをクリック → `/game/guide` ページへ遷移することを確認
3. トップページの「Some Links」カテゴリの「Pixiv」ボタンをクリック → 新しいタブで `https://www.pixiv.net/users/74381242` が開くことを確認

**期待結果**: 内部リンクは同一タブで遷移、外部リンクは新規タブで開く。

### シナリオ 3: テーマ切り替え（User Story 3・FR-005）

**手順**:

1. フッターのダークテーマボタンをクリック → ページ全体がダーク配色に即座に切り替わることを確認
2. ページをリロード → ダークテーマが維持されることを確認
3. フッターのシステムテーマボタンをクリック → OS の配色設定に追従することを確認
4. ブラウザの開発者ツールで `localStorage["theme"]` の値が `light` / `dark` / `system` のいずれかであることを確認

**期待結果**: テーマ切替が 1 クリックで完了し、リロード後も選択が維持される。初回訪問時（未保存）はシステム設定に基づく配色が適用される。

### シナリオ 4: 検索モーダル（User Story 4・FR-006）

**手順**:

1. ヘッダーの検索ボタンをクリック → モーダルが開き、検索入力欄が表示されることを確認
2. モーダル内に全コンテンツの一覧が表示されることを確認（コンテンツが 0 件の場合は「コンテンツがありません」と表示される）
3. 閉じるボタン / バックドロップクリック / Esc キーでモーダルが閉じることを確認

**期待結果**: モーダル表示と全コンテンツ一覧表示が動作する（キーワード検索ロジックは後続フェーズのため未実装）。

### シナリオ 5: レスポンシブ表示（FR-007）

**手順**:

1. ブラウザの開発者ツールで画面幅を 375px（モバイル相当）に変更
2. トップページを確認 → ヘッダーのナビゲーションが折り返して表示され、カテゴリボタン群が縦積みになることを確認
3. デスクトップ幅（1280px）に戻し、3 列レイアウトに戻ることを確認

**期待結果**: いずれの画面幅でもレイアウトが崩れず、主要リンクに到達できる。

### シナリオ 6: 404 ページ（エッジケース）

**手順**:

1. 存在しない URL（例: `http://localhost:4321/nonexistent`）を開く
2. 「404: ページが見つかりませんでした。ごめんね。」と「トップに戻る」ボタンが表示されることを確認
3. 「トップに戻る」ボタンでトップページへ遷移することを確認

**期待結果**: 未作成ページへの遷移時に 404 ページが表示される。

### シナリオ 7: RSS フィード（FR-002 のリンク先）

**手順**:

1. ヘッダーの「RSS」リンクをクリック → `http://localhost:4321/rss.xml` が RSS 2.0 形式の XML として返ることを確認
2. `<channel><title>Magia Laboratory</title>` と `<language>ja</language>` が含まれることを確認

**期待結果**: RSS フィードが正しい形式で配信される。

## 自動チェック

実装完了時は以下を実行し、すべて合格すること（憲章の品質ゲート）。

```bash
# 型チェック・lint・テストの一括実行
bun run totalcheck

# カバレッジ確認（目標 95%）
bun run coverage
```
