# Feature Specification: 個人創作サイト（Astro + Svelte）

**Feature Branch**: `001-personal-creative-site`

**Created**: 2026-08-24

**Status**: Draft

**Input**: User description: "旧レイアウトを引き継いで、Astro+Svelteの個人創作サイトを作りたい"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - サイト全体のレイアウトとナビゲーション (Priority: P1)

訪問者がサイトを開くと、旧サイト（Magia Laboratory）と同じ見た目・構成のトップページが表示される。画面上部に固定ヘッダー（サイトタイトル・ナビゲーション・検索ボタン）、中央に各コレクションへのリンク群、下部にフッター（コピーライト・テーマ切替・プライバシーポリシー・トップへ戻るボタン）が配置される。

**Why this priority**: サイトの骨格となるレイアウトであり、これが無ければ他のどの機能も成立しないため最優先。

**Independent Test**: 開発サーバーを起動してトップページを開き、ヘッダー・メイン・フッターの3領域が旧サイトと同等の配置で表示されることを目視確認できる。

**Acceptance Scenarios**:

1. **Given** 訪問者がサイトのトップページを開いたとき、**When** ページが読み込まれると、**Then** 上部に固定ヘッダー、中央にタイトルとリンク群、下部にフッターが表示される。
2. **Given** 訪問者がヘッダーのナビゲーションリンクをクリックしたとき、**When** リンク先が存在する場合、**Then** 対応するページへ遷移する。
3. **Given** 訪問者がページをスクロールしたとき、**When** ヘッダーが固定表示されている場合、**Then** ヘッダーは画面上部に留まり続ける。

---

### User Story 2 - トップページのコンテンツ表示 (Priority: P1)

トップページには、サイトタイトル「Magia Laboratory」と説明文、および「Game」「Creation」「Lily」「etc.」「Some Links」の各カテゴリに属するリンクボタンが表示される。訪問者はこれらのボタンから各コンテンツへ移動できる。

**Why this priority**: サイトの入口として、訪問者を各コンテンツへ誘導する中核機能であるため。

**Independent Test**: トップページを開き、各カテゴリのリンクボタンが旧サイトと同じラベル・並びで表示され、クリックで遷移することを確認できる。

**Acceptance Scenarios**:

1. **Given** 訪問者がトップページを開いたとき、**When** ページが表示されると、**Then** サイトタイトルと説明文が中央に表示される。
2. **Given** トップページにカテゴリリンクが表示されているとき、**When** 訪問者が「Game」ボタンをクリックすると、**Then** Game カテゴリのページへ遷移する。
3. **Given** トップページに外部リンクが表示されているとき、**When** 訪問者が「Pixiv」等の外部リンクをクリックすると、**Then** 新しいタブで該当の外部サイトが開く。

---

### User Story 3 - テーマ切り替え（ライト/ダーク/システム） (Priority: P2)

訪問者はフッターのボタンでライト・ダーク・システムの3つのテーマを切り替えられる。選択はブラウザに保存され、次回訪問時にも維持される。

**Why this priority**: 閲覧環境に応じた表示を提供する利便性機能であり、レイアウト完成後に追加する。

**Independent Test**: フッターのテーマボタンをクリックし、配色が即座に切り替わり、リロード後も選択が維持されることを確認できる。

**Acceptance Scenarios**:

1. **Given** 訪問者がフッターの「ダーク」ボタンをクリックしたとき、**When** テーマが切り替わると、**Then** ページ全体がダーク配色になる。
2. **Given** 訪問者が「システム」を選択しているとき、**When** OS の配色設定がダークの場合、**Then** ページはダーク配色で表示される。
3. **Given** 訪問者がテーマを選択した後、**When** ページをリロードすると、**Then** 選択したテーマが維持される。

---

### User Story 4 - 検索機能 (Priority: P3)

訪問者はヘッダーの検索ボタンから検索モーダルを開き、サイト内のコンテンツを検索できる。

**Why this priority**: コンテンツが増えた際の利便性向上であり、初期段階では必須ではない。

**Independent Test**: 検索ボタンをクリックしてモーダルが開き、キーワード入力で該当コンテンツが表示されることを確認できる。

**Acceptance Scenarios**:

1. **Given** 訪問者がヘッダーの検索ボタンをクリックしたとき、**When** モーダルが開くと、**Then** 検索入力欄が表示される。
2. **Given** 検索モーダルが開いているとき、**When** 訪問者がキーワードを入力すると、**Then** 該当するコンテンツの一覧が表示される。

---

### Edge Cases

- ナビゲーションリンク先のページが未作成の場合、訪問者にどう見えるか（404 ページの表示）。
- テーマ選択が保存されていない初回訪問時、システム設定に基づくデフォルト配色が適用されるか。
- 検索対象のコンテンツが存在しない場合、検索結果が空である旨が表示されるか。
- モバイル等の狭い画面幅で、ヘッダーのナビゲーションが折り返して表示されるか。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは旧サイト（Magia Laboratory）と同等のレイアウト（固定ヘッダー・メイン・フッター）を提供しなければならない。
- **FR-002**: システムはヘッダーにサイトタイトル、ナビゲーションリンク（Game / Lily / Creation / Diary / RSS）、検索ボタンを表示しなければならない。
- **FR-003**: システムはトップページにサイトタイトル・説明文・各カテゴリのリンクボタン群を表示しなければならない。
- **FR-004**: システムはフッターにコピーライト、プライバシーポリシーへのリンク、テーマ切替ボタン、トップへ戻るボタンを表示しなければならない。
- **FR-005**: システムはライト・ダーク・システムの3つのテーマを切り替えられ、選択をブラウザに永続化しなければならない。
- **FR-006**: システムは検索ボタンから検索モーダルを開き、サイト内コンテンツを検索できなければならない。
- **FR-007**: システムはレスポンシブ表示に対応し、モバイル等の狭い画面幅でもレイアウトが崩れないようにしなければならない。
- **FR-008**: システムはサイト全体のメタ情報（タイトル・説明・著者）を一元管理しなければならない。

### Key Entities *(include if feature involves data)*

- **サイトメタ情報**: サイトタイトル、説明文、著者名などのサイト全体の定数。
- **ナビゲーション項目**: 表示ラベルとリンク先 URL の組。ヘッダー・トップページで参照される。
- **テーマ設定**: ライト / ダーク / システムのいずれかの値。ブラウザに保存される。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 訪問者はトップページを開いてから3秒以内に主要なナビゲーションリンクを視認できる。
- **SC-002**: テーマ切り替え操作が1クリックで完了し、反映が即座（1秒以内）に視認できる。
- **SC-003**: モバイル・デスクトップのいずれの画面幅でもレイアウトが崩れず、主要リンクに到達できる。
- **SC-004**: 旧サイトと比較して、トップページの主要要素（タイトル・カテゴリリンク・フッター）が同等の配置で再現されている。

## Assumptions

- 対象ユーザーは旧サイト（Magia Laboratory）の訪問者と同様、ゲーム攻略・百合作品・創作コンテンツに関心のある一般閲覧者である。
- コンテンツ（Markdown 等）の実データ移行は本仕様の範囲外とし、まずレイアウトと骨格の再現を優先する。
- 検索機能は初期段階ではプレースホルダー（モーダル表示のみ）でも許容し、本格的な検索ロジックは後続で実装する。
- テーマのデフォルトは「システム」とし、OS の配色設定に追従する。
- 外部リンク（Pixiv / YouTube / GitHub / X 等）は旧サイトと同じ URL を引き継ぐ。
