# Magia Laboratory

Astro/Svelteベースの静的サイトジェネレーター（SSG）プロジェクトです。
Markdownによるコンテンツ管理と、UnoCSSによるスタイリングをサポートしています。

## 特徴

- **Astro**: MarkdownによるSSG
- **Svelte**: 高速な静的サイト生成
- **UnoCSS**: ユーティリティファーストの高速なCSSエンジン

## 開発環境のセットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```
